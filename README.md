# Resume-Tex

A LaTeX resume based on the elegant [AltaCV](https://github.com/liantze/AltaCV) template.

## Overview

This repository contains the LaTeX source files for my professional resume, built using the AltaCV template by liantze. The AltaCV template provides a modern, visually appealing format for creating CVs and resumes in LaTeX.

## Prerequisites

To compile this resume, you'll need:

- A LaTeX distribution (like TeX Live, MiKTeX, or MacTeX)
- XeLaTeX or LuaLaTeX compiler (recommended for font handling)

## Usage

1. Clone this repository:
   ```
   git clone https://github.com/nihalshahria/resume-tex.git
   cd resume-tex
   ```

2. Edit the `.tex` files to update your personal information, experiences, skills, etc.

3. Compile the document using XeLaTeX:
   ```
   xelatex mmayer.tex
   ```

4. Alternatively, if you're using an editor like Overleaf, simply upload the files and compile there.

## Customization

- Edit the main `.tex` file to update content
- Modify the `altacv.cls` file to change colors, spacing, and formatting
- Add or remove sections as needed for your specific resume requirements
